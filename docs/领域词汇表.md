# 领域词汇表

> 核对：2026-11-20 0.2.4

本文档定义 MypiPlugin 代码、配置与文档中使用的统一术语；模块实现与流程边界见 [架构说明.md](架构说明.md)。

| 术语 | 定义 |
|---|---|
| **Pi** | 独立运行的 coding agent CLI（npm 包 `@earendil-works/pi-coding-agent`），在项目根目录下运行，可直接读取项目文件并调用 MCP 工具。 |
| **Reworked Terminal** | IntelliJ IDEA 2026.2+ 提供的内置新终端实现（`org.jetbrains.plugins.terminal`），暴露 `TerminalToolWindowTabsManager`、`TerminalView` 等 `@ApiStatus.Experimental` API。 |
| **单会话（Single Session）** | 同一 IntelliJ `Project` 仅维护一个标题为 `Pi` 的终端 Tab；已开启时点击图标只聚焦不重开，Tab 关闭后自动清理引用以允许重启。 |
| **定位串（Location Reference）** | 注入到 Pi 终端的纯位置引用文本（不含代码正文），分为冒号风格（`COLON_LINE`，`@path:10-20` / `@path:42`）与 GitHub 风格（`GITHUB_ANCHOR`，`@path#L10-20` / `@path#L42`）。 |
| **只填不发送（Paste Without Execute）** | 通过 `TerminalView.createSendTextBuilder()` 启用 bracketed paste 与 `sendEndKeyBeforeText()`，不触发回车执行，保留给用户补充问题后手动回车。 |
| **焦点接力（Focus Handoff）** | 定位串注入成功后自动选中 `Pi` Tab、激活底部 `Terminal` 工具窗并将键盘焦点移交到 `TerminalView.preferredFocusableComponent`。 |
| **IDE MCP 自动集成** | 启动 Pi 终端前通过反射获取 IDEA 内置 MCP Server（2025.2+）的 SSE 地址，并写入用户级 `~/.pi/agent/mcp.json` 的 `mcpServers.intellij`。 |
| **MCP 去重检测** | 当 `~/.pi/agent/mcp.json` 的 `imports` 含 `claude-code` 且 `~/.claude.json` 已存在同 `host:port` 的 MCP Server 时，跳过重复注入。 |
| **Tier1 / Tier2 测试分层** | **Tier1** 为零 IntelliJ 平台依赖的 JUnit 5 纯逻辑单测（CLI 秒跑）；**Tier2** 为继承 `BasePlatformTestCase` 的平台集成测试（需在真实 IDE 中执行）。 |
| **Plugin Verifier 双端检查** | 通过 `./gradlew verifyPlugin` 同时对声明兼容范围的最低支持版与最新支持版 IDE 做二进制兼容校验。 |
| **单一真相源（SSOT）** | 插件版本与兼容范围仅维护在 `gradle.properties`，插件描述仅维护在 `plugin.xml`，发版流水线与自定义仓库索引 `updatePlugins.xml` 均自动提取，不二次硬编码。 |
